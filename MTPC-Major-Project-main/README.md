# 🏥 MTPC — Mother Teresa Palliative Care Management System

A comprehensive **PHP & MySQL-based Palliative Care Management System** developed as an MCA Major Project. The system is designed to streamline the management of patients, volunteers, staff, medical records, donations, events, and day-to-day operations of Mother Teresa Palliative Care.

The application can be deployed on any standard PHP hosting server or run locally using XAMPP, WAMP, or LAMP.

# 📌 Project Overview

The **Mother Teresa Palliative Care Management System (MTPC)** is a web-based application developed to simplify and digitize the management of palliative care services.

The system helps administrators efficiently manage patients, staff, volunteers, appointments, medical records, donations, events, and organizational activities through a centralized platform.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Hazy-Arrow/MTPC-Major-Project.git
```

---

## 2️⃣ Move Project Folder

Copy the project folder into:

```bash
htdocs/
```

(for XAMPP)

---

## 3️⃣ Start Local Server

Start the following services using XAMPP/WAMP:

* Apache
* MySQL

---

## 4️⃣ Create Database

* Open phpMyAdmin
* Create a new database (e.g., `mtpc`)
* Import:

```bash
database.sql
```

---

## 5️⃣ Configure Database Connection

Update the database credentials in:

```bash
includes/config.php
```

Example:

```php
<?php
$host = "localhost";
$user = "root";
$password = "";
$database = "mtpc";
?>
```

---

# ▶️ Run the Project

Open your browser:

```bash
http://localhost/MTPC
```

or

```bash
http://localhost/MTPC-Major-Project
```

depending on the project folder name.
